## 已复刻的窗口与行情规则

`WindowChrome` 将主窗口设为全屏布局，状态栏和导航栏透明，背景与页面主题一致；`Index` 用系统实际避让区设置内容安全边距，配置变化时更新栏内文字色。登录滚动容器明确顶部对齐。此前上下 RGB(0,0,0) 黑边的真机截图回归失败，修复后深色为 RGB(33,39,49)、浅色为 RGB(255,255,255)。不要用固定设备高度、删除安全边距或隐藏系统栏替代该逻辑。

认证保留原生密码眼睛、焦点与输入键盘，注册状态加载／关闭／读取失败时阻断提交；协议弹层关闭后保留当前表单。为保持与 iOS 相同的可见布局，未登录服务器设置从品牌区域长按进入。真实认证请求仍由现有 Session 执行，离线预览禁止认证写入。

交易对来自 `/api/market/symbols`，不以 ticker 数量替代目录；搜索忽略大小写和 `/`，自选优先。名称首次升序，其余首次降序，再次反向、第三次恢复手工顺序；同值按名称升序，缺报价置后。显示精度对齐 iOS `DisplayNumber`，交易请求精度不受影响。列表使用稳定币种身份，返回行情保留排序及滚动位置。

自选按服务地址＋用户保存，350 ms 合并同步 `/api/market/watchlist`；本地编辑和空列表优先保留，失败标记待同步，后续启动／加载目录重试。旧默认响应不能覆盖正在编辑的列表，旧会话不能解锁新会话的同步请求或覆盖新账户提示。带单／普通模式共用同一用户自选；其余账户能力仍按会话模式隔离。

## 图表与开仓规则

周期按当前 iOS `MarketKlineInterval` 的13项枚举排列；快捷周期至少1项、最多6项，当前周期始终可见。`chart-favorites-v1`、`chart-parameters-v1` 与 `chart-auto-fit` 保存本机图表偏好。主图左右留白为4／58 vp，绘图区为正方形，图例30 vp、时间轴24 vp、副图每项74 vp；底部票据固定，图表区域可滚动。Canvas 字体使用 vp，避免高密度手机按物理 px 缩小。

指标由独立 `Indicators.ts` 计算并按行情／参数版本缓存；移动光标或平移不重复计算整批指标。默认 MA 为7／25／99、EMA为21／55／144、Super为10／6；EMA及MACD使用当前 Swift 的均值种子与预热，时间缺口重置，末根更新不会重复累计。`generate-ios-chart-reference.py` 从当前 Swift 计算器生成两组公开合成行情（连续／缺口，包含末根与统计缺值），覆盖20类指标；不是用鸿蒙实现生成期望值，也不包含账户数据。

auto按可见K线与覆盖指标求价格域；手动模式支持价格域平移／缩放。长按后同次触摸跟随，松手保留光标，后续新的平移移除光标；第二根手指可以接管进入缩放，并屏蔽迟到的单指回调。限价开仓／止损线可分别拖动并随相对位置切换多空；切周期或返回编辑页保留绘图，换币种重置意图。已有持仓展示开仓、实际市价止损、手动止盈及B／S标记，不能拖动这些保护线。

票据的估算、含费、策略快照与杠杆都属于冻结参数；异步初筛／预检／确认期间若账户、页面或参数变化，则终止旧意图。提交前和确认后均重读持仓；持仓数量缺失或响应畸形时阻断新开仓。市价先做限时EMA方向初筛，再点一次进入资金预检与确认；限价直接预检。确认后的请求仍走原有持久化 Commands，未决请求禁止换参数新发。没有策略字段表示手动止盈，与当前后端解析保持一致。

## 离线真机预览

`scripts/prepare-preview.mjs` 生成独立忽略工程 `.local-build/preview-project/`，仅在该副本替换 Runtime。预览的 Transport、Socket、Vault 和 Preferences 都为内存替身；外部地址以及认证、交易、账户和资金写入会被拒绝，仅允许本地模拟自选保存，以及图表场景中的EMA初筛／资金预检查，不读写手机真实会话或偏好。固定行情用于布局和交互，不能作为行情准确性或网络性能证据。

可分别选择 auth／market／chart／chart-held／chart-error、light／dark 和注册 open／closed／unavailable，命令见 [工程 README](../frontend/harmony-app/README.md)。预览和正常包使用相同测试签名、包名，测试结束必须重新同步并安装正常签名包；禁止把预览包作为交付包或将替身混入正常 Runtime。截图、布局、日志和 HAP 只保存在 `.local-build/`。

## 资金与身份安全

金额、比例和请求字段使用十进制字符串。`Decimal.ts` 实现定点加减乘除与舍入；价格绘图和指标才使用浮点数。止损预估遵循服务端1／5／10 USDT阶梯向上取整，实际结果以服务器为准。普通测试不真实开平仓、划转、撤保护或更改已有订单策略，规则见 [交易安全](trading-safety.md) 和 [资金](capital-and-transfers.md)。

会话使用 Bearer header；refresh cookie 与访问 token 只写 Asset Store，不写 Preferences。安全存储按1000字节分块，先写分块再提交清单，串行读写；锁屏或写入失败时阻止新增交易。Preferences 仅存 HTTPS 地址、主题、自选和图表偏好。HTTP／WSS 保留系统 TLS 校验，不添加忽略证书错误的逻辑。

会话代际覆盖退出、服务地址、用户、模式和本机绑定变化。旧 HTTP 响应及旧 WSS 回调不能覆盖新身份；401 刷新合并为单在途，原请求最多重试一次。`/v1/api/info` 目前只给出 alias/status，没有服务端绑定代际：客户端持久化本机 epoch，在本机绑定／解绑时轮换，连接状态变化不当作新账户。**其他设备用相同别名替换 API 的场景无法仅凭此协议在客户端提前识别**，最终绑定指纹及代际隔离继续由服务端检查；后续可考虑提供不含凭证的绑定身份接口。

所有交易命令先把 action、冻结参数和稳定幂等键写入安全存储，再发送。未知结果重启后沿用原键；已有 command ID 只查询该 ID；当前身份存在未决请求时阻止更换参数另发命令。批量平仓先保存整批目标和逐笔键，成功／明确失败才推进游标；UNKNOWN 或账户切换时停止后续目标，即使本机游标写失败也不会重新生成键。

资金整理使用独立本机安全记录：首次请求前记录未知状态，收到 `collection_id` 后先保存，再允许核对同一流水；没有 ID 的异常不重发原计划。重新预览若返回待确认流水则恢复 ID，返回 ready/not_required 才清理未知记录。无法确定结果时保持阻断。操作目的、计划 token、金额、网络与目标地址按现有资金状态机交给服务器确认。
