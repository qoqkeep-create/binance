# 账户、归集、交易对与图表界面调整

目标：按本轮用户反馈修正账户与归集布局、统一底部弹窗、交易对服务器排序及图表开仓交互。

设计与实施顺序：
1. 账户卡加深黄色，移除菜单里的重复资金归集入口，保留资产卡归集余额。
2. 刷新放在划转方向／转出账户标题右侧，底栏只保留金额与提交；iOS 26 统一使用贴边的大尺寸 sheet，账号编辑从已读数据直接初始化。
3. 小于 1 的数按最多四位有效数字四舍五入并去掉末尾零。大于等于 1 的规则沿用现行分档；展示不改交易精度。
4. 市价估算随主图十字线选价，十字线消失或进入副图清空；限价保留两根可拖动委托线。左侧标签等宽、右移，右侧价格进入价格轴。当前价线横贯主图，价格标记收紧并右对齐。
5. 开仓区使用三列两行，固定手续费开关尺寸，调整止损额入口，增加策略选择与手动止盈。默认策略只影响以后新单。
6. 自选按用户保存在服务器并保留本地离线待同步记录；列表先自选，再按服务器市值降序。CoinGecko 公共市值每周更新，失败保留旧快照，页面读取不调用第三方。

验证：增加数字、自选隔离／持久化／失败恢复、市值更新与排序、手动止盈回归；运行隔离后端测试与 host Swift 数字测试，编译 iOS Release 和测试目标。按用户偏好不启动模拟器，iPhone 16 Pro Max 视觉及触摸验收需手机新版确认。更新各主题主文档，保留工作区其他改动。
