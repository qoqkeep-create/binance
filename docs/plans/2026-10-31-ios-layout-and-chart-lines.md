## 实施清单

1. K 线页顶部左右边距从 11pt 调整为左 4pt / 右 11pt，缩小返回与币种信息的间隔，保留 44pt 点击区域。
2. 初始 K 线槽宽从 5.8pt 增至 7.6pt，使 390pt 屏幕约从 57 根降至 43 根；缩放上下限保持。
3. EMA 维持默认 21/55/144；增加专用颜色 token，避免影响 MA/BOLL/MACD。参考图嵌入 Display P3，转为 sRGB 后文字实色取样为 #2DBD85 / #3860F6 / #71269C。
4. 以可执行复现定位布林带毛刺，检查数值稳定性、线段连接及 Metal 边缘覆盖；新增能捕获缺陷的回归并记录证据。
5. 信号卡片：价格标签与数值在右侧上下排列，时间右下，减小内外垂直留白。
6. 行情涨跌胶囊背景为 #32BD82 / #F6485E，文字缩至 13pt 并设白色，圆角 4pt；表头两行 24h / 涨跌幅，保持现有数据口径。
7. 明亮模式底栏选中 #010101，未选中 #767676；暗色沿用原 token。
8. 持仓三个页签与设置页顶部标题使用信号页的 modalTitle 及 primaryText，未选中页签也保持一致文字色。
9. 外观改为暗色模式开关：关闭亮色、开启暗色，继续保存原外观偏好。
10. 止损额作为独立行移到绑定 API 上方；顶部账户卡使用约 16% 透明度黄色底。
11. 持仓未绑定账户的图标可点击，push 复用 API 绑定界面，返回后刷新账户数据。

## 实施记录

- 11 项界面调整已实现。信号卡片保留二次提醒信息，减少普通行留白；持仓绑定入口复用原绑定表单与服务端校验。
- BOLL 原公式 `E[x²] - E[x]²` 在高价低波动数据上发生浮点抵消。复现的带宽误差约 `6.9168`，改为中心化两遍方差后约 `7.4×10⁻⁹`。
- 原 Metal 线条只绘制不透明四边形，四种斜线/接头/虚线场景的过渡边缘像素数均为 0；增加物理像素覆盖率、圆形端点与虚线边缘过渡后分别为 `204 / 148 / 257 / 167`。
- 指标历史/实时曲线、用户画线和圆角标记边框均接入抗锯齿。网格、蜡烛及填充块保留原路径。
- 新增 macOS 可执行回归脚本 `frontend/ios-app/scripts/check_chart_lines.py`，直接编译生产 BOLL 和 Metal shader；新增 XCTest 用例覆盖 EMA 配色、BOLL 平移稳定性及 2x/3x 离屏线条。
- 84 个应用源文件和 7 个测试源文件已使用 CLT Swift 与 iOS Simulator SDK 完成类型检查，应用模块生成通过；91 个 Swift 文件语法、工程 plist 和现有 CI 脚本回归通过。完整 XCTest/模拟器页面验收仍受当前 Xcode 许可状态限制，未宣称已执行。
