# 首页行情行距调整

## 目标与设计

首页行情采用更紧凑的双行布局：最小行高设为 52pt，币种与成交额、价格与美元参考价之间的垂直间距均设为 3pt。以 52pt 最小高度保留点击空间，使用 `minHeight` 允许大字体自然撑高；通过矩形 `contentShape` 覆盖整行点击区域。

## 实施范围

- `BinanceTheme.Layout.marketRowHeight`：调整首页行情行高。
- `MarketTickerRow`：收紧两列文字间距，补全整行点击区域。

## 验证

- 布局检查：52pt 最小行高大于 44pt 最小点击尺寸，双行文字与涨跌幅标签保留自然高度；大字体可继续撑高行高。
- 本地 Mac Catalyst 预览构建通过（`TradeTool Release`）。本机暂无 iOS 模拟器运行时，本次未执行模拟器测试。
- 提交范围仅包含首页行高、文字间距、点击区域与本文档；通过独立 Git 索引保留工作区已有改动及其暂存状态。
