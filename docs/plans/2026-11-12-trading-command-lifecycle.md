# 交易命令生命周期收敛

## 目标

让市价、Maker、限价开仓都遵循同一条可解释规则：交易所确认成交才形成持仓；挂单成功只显示为委托；写请求结果未知时不重发，由用户主动核对。

## 规则

- `TradingCommand` 记录请求投递结果，不代表成交结果。
- `TradeOpenRequest` 记录一次开仓意图和幂等身份。
- `LimitOrder` 记录交易所未完成委托。
- `Order` 只代表已确认成交的本地持仓。
- `UNKNOWN` 只允许查询、核对、撤单和减仓等风险降低操作；新增风险写入保持阻塞。
- `entry-status` 只读查询交易所订单。它可以接管交易所已确认的成交，但绝不重新下单。
- Maker 的 `PENDING_MAKER` 与限价的 `PENDING_LIMIT` 都直接进入委托页。
- 确认终态后解除原未知命令；没有交易所证据时保持未知，不按时间猜测失败。

## 失败边界

网络中断、交易所 5xx 或无法取得订单事实时保持 `UNKNOWN`。止损保护属于成交后的独立状态；成交已确认但止损未就绪时显示保护待处理，不把持仓伪装成开仓失败。

## 验证

覆盖幂等、未知不重发、Maker 待成交／成交／零成交终态、限价核对、手动核对解除阻塞、绑定代际隔离，以及客户端标准错误弹窗和委托页刷新。
