# iOS 运行时服务器切换

目标：让国内客户端在旧环境与首尔测试环境间切换，并能在设备上测量网络响应。

## 行为

- 设置页新增“切换服务器”，登录页也保留入口，当前服务器不可达时仍能切回。
- 固定提供原服务器 `https://binance.oovso.com:8443` 与首尔服务器
  `https://47.80.22.243`；开发构建还保留其配置中的局域网环境。
- 首次启动使用构建配置；之后使用本机保存的选择。未知保存地址不加载。
- 切换前匿名检查目标服务。失败或取消时保留原会话；成功后关闭旧 HTTP / WSS
  及页面任务，保存选择，重建 AppContainer 和根视图，恢复目标来源自己的登录态。
- 使用应用内完整重新载入。iOS 没有公开的应用自行退出并自动重新启动机制，
  不调用退出或私有 API。参考 [Apple QA1561](https://developer.apple.com/library/archive/qa/qa1561/_index.html)。

## 会话与错误

Keychain 延续按协议、主机、有效端口隔离的现有规则。每个容器使用独立 URLSession
和认证事件 NotificationCenter，旧请求的 401 不会清除新环境的会话。
服务器账号、交易绑定及数据各自独立，切换不迁移数据。

网络按钮使用独立 ephemeral URLSession，访问不带凭证的 `/api/auth/me`，
验证来源、HTTP 状态及 JSON code。正常 401 视为可连接，不触发登录失效。
每台采集 3 次并显示中位数，失败显示原因；切换再次检查，不依赖过期测试结果。
TLS 校验保持开启。

## 验收

- XCTest：选择持久化、未知地址拒绝、成功重建、失败保留、取消不提交、匿名探测、
  非 API 响应拒绝、旧来源认证事件隔离。
- iOS SDK 构建应用与测试目标；本机无 iOS Simulator runtime，因此通过临时
  Mac Catalyst 工程实际运行原生客户端与 7 项测试，平台改动不进入项目。
- 人工核对登录页和设置页入口、网络按钮、来回切换和重新载入；国内真机仍需复测。
- 使用生产网络代码运行交替测试，保留 [结果和限制](../SERVER_NETWORK_COMPARISON_2026-10-31.md)。
