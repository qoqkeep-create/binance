## 演进背景

- 早期 PRD / spec / tasks / OpenAPI 曾面向 OKX，含 passphrase、旧账户模型、旧站点 URL 与旧认证响应。当前实现已转向 Binance；部分类名、迁移和路由保留历史名字以兼容数据。
- 2026-06 的研究计划描述样本、研究数据包、AI 草稿、策略发布和回测。随后实现与早期方案不同，例如现在是共享模型目录 + 用户选择，而非完整私有模型管理接口；旧市场分析 HTTP 页面也不是当前路由。
- 2026-08 的资金与安全设计来自真实保护误操作风险。当前保留发布 / 交易分权、保护对账和用户确认资金规范化；旧管理员口令 / 数据库触发器和即时缺止损告警没有完整落地依据。
- 2026-09 的多份计划逐步调整了外部信号格式、来源页签、通知精简、独立投递、转账入库 / 刷新、行情缓存与 WS。计划间存在先后替代关系，最终行为按现行主题文档和源码核对。
- 用户后续暂停“无持仓 + 限时 SSH 窗口”的旧发布规则，允许不影响现有持仓的开发版本直接 webhook / SSH 部署；未来仅 webhook 要等新的明确通知。

## 为什么不继续保留旧操作手册

旧文件包含过期证书日期、移除宿主 Nginx 的部署建议、直接查看整份环境文件或修改交易状态的示例，以及“计划实施”与“已上线”混写。继续放在当前目录容易被直接照做。

有维护价值的架构、限制、接口、排障和待办已转入现行文档；重复镜像文件与一次性任务清单删除。历史原文仍可用 Git 只读查看，不应按其中命令操作线上。

`对话指令原文.md` 是本地忽略的用户材料，本轮未改动或删除；它不是供合作方分发的接口文档，也不应提交潜在敏感内容。
